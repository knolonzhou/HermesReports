### 4. 只看车牌，就能解锁某大品牌在全球的大部分汽车（575 分 / 313 评论）

**背景**：现代联网汽车都能用手机 App 远程解锁、鸣笛、启动发动机——这些指令最终都要经过厂商的云端服务器。**发生了什么**：安全研究员 Shubs 和 Sam Curry 对某大厂（文中匿名，评论区从照片里的车型推断是丰田/雷克萨斯，未经证实）的车联网平台做渗透测试，拼出一条完整攻击链：车牌 → 公开注册查询拿到 VIN（车架号）→ 厂商暴露在互联网上的管理后台 API 查到车主账户 → 后台 JS 代码里竟然硬编码了身份系统 ForgeRock OpenIDM 的管理员密码 → 用路径穿越（在 URL 里塞 `..%2f` 这类"往上级目录跳"的字符绕过防火墙规则）访问敏感接口 → 利用 OAuth 的 ROPC 流程绕过 MFA（多因素认证，即密码之外的第二道验证）伪造任意用户的 App 令牌 → 调远程指令 API：车门解锁。美加澳全部沦陷。**为什么值得看**：每一步单独看都不算高深——泄露的密钥、没藏好的管理后台、能被绕过的 WAF（Web 应用防火墙）——但串起来就是"知道车牌就能开走你的车"。**评论区两派**：一派认为不必恐慌——这需要顶级研究员花数周，普通小偷还是砸窗户来得快，"任何锁都能被撬，锁只是防君子"；另一派认为这恰恰说明问题——车厂把"必须联网的远程控制"做成了标配，等于给每辆车装了一个永远暴露在互联网上的攻击面，而且厂商显然知道 OpenIDM 暴露很危险（专门配了 WAF 规则），却因为业务需要不肯下线，"创可贴式安全"终究会漏。

### 5. Outlook.com 开始悄悄拒收没有 DMARC 记录的域名的邮件（518 分 / 346 评论）

**背景**：DMARC 是一种 DNS 记录（域名的"公告栏"里的一条 TXT 文本），告诉收件方"冒充我域名的邮件该怎么处理"，配合 SPF/DKIM（两种证明邮件真的来自声称发件人的签名机制）防钓鱼。2025 年 5 月起微软只要求日发 5000 封以上的大发送方必须有 DMARC。**发生了什么**：11 月 5 日起，Outlook/Hotmail/Live/MSN 开始对**所有**没有 DMARC 记录的域名退信（报错 `550 5.7.1 Message lacks SPF/DKIM/DMARC Auth Records`），且没有任何公告；更坑的是只拒收一部分邮件——同一域名一封信能过、下一封被退，让小发件人误以为是偶发故障。**为什么值得看**：如果你有自己的域名邮箱，给 Outlook 用户的发票、预约确认可能正在无声消失。修复只要一条 DNS 记录：`_dmarc` → `v=DMARC1; p=none`（p=none 表示"先只报告不拦截"，对其它收件方零影响），用 `dig +short TXT _dmarc.你的域名` 几秒钟就能自查。**评论区两派**：一派支持——钓鱼邮件泛滥，DMARC 早该是底线，"拒收无 DMARC 邮件本身没毛病，有毛病的是不吭声"；另一派（大量自托管邮件用户）愤怒——微软凭不公开的黑名单静默丢信、申诉无门，是压死个人邮件服务器的又一根稻草，"联邦制网络里任何握有 10% 用户的巨头都能对整个生态立法"，还有人补充 Google 同样糟糕甚至更糟。双方共识：小发件人是最受伤的，巨头规则从不为他们设计。

### 7. 《经济学人》：人类再也不会做出维基百科这样的项目了（438 分 / 367 评论）

**背景**：维基百科是人类史上最大的志愿者协作工程，靠"任何人可编辑、不商业化、共识治理"运转了 25 年。**发生了什么**：《经济学人》刊文认为这样的项目已成绝响：互联网被平台和算法收编，年轻一代在企业 App 里长大、对"非商业的公共品"陌生甚至警惕，Stack Overflow 等社区贡献者锐减，而 AI 生成内容的洪水让"人工众包"显得既慢又贵。**为什么值得看**：它戳中一个时代情绪——公共互联网还能不能有新的"大教堂"？**评论区两派非常精彩**：悲观派举 OpenStreetMap（开放地图，维基模式的地理版）为例：地图填满后新手看不到可贡献的空白、企业成了最大受益者后理想主义者问"凭什么义务劳动喂公司"、社区老编辑对新人的修改秒回滚（有立陶宛用户吐槽某地把地图当私产、德国用户说改错几条河就被怼到放弃）。乐观派则由 SponsorBlock 作者（YouTube 跳过广告片段的众包浏览器插件）亲自下场反驳：他的项目每周 17% 的提交者是首次贡献、19% 已坚持三年以上，规模持续增长，"众包没死，只是不再上头条"；跟帖有人晒统计：自己随手标的每个广告片段平均帮 682 人省了时间。中间派补刀：技术从来不是瓶颈——"我们几千年没再建金字塔，不是因为不会，而是没人愿意"；真正的稀缺品是组织信任和无偿奉献的社会氛围。

### 11. Next-Concept Modeling：文本也能"先画草稿再细化"，比扩散模型快 10-31 倍（166 分 / 38 评论）

**背景**：现在所有主流 LLM 都是自回归（autoregressive，一个 token 一个 token 往外蹦，像用圆珠笔逐字写字）。扩散语言模型（DLM，diffusion language model）是另一条路线：像画画一样从一团噪点开始、多轮去噪、一次"显影"出很多词，理论上快得多——但实际有三个毛病：去噪步数一少质量就崩、每一步都要处理整个序列（贵）、训练要吃很多遍数据。**发生了什么**：斯坦福团队提出 NCM（Next-Concept Modeling）：先用一个多尺度残差 VQ-VAE（一种把文本压缩成"分层离散码本"的编码器——粗层码短、只含大意，细层码长、含逐字细节，类似 JPEG 先存轮廓再存纹理的思路）把文本编码成 K 层码，再让 Transformer 一层一层生成：每层内部所有码**并行**预测，层与层之间由粗到细。**为什么值得看**：数字很硬——同样参数量下，在 LM1B 数据集上生成质量超过最强扩散基线还快 21 倍，摘要任务快 31 倍，训练 token 少 4-5 倍；连数独这种推理任务都全面赢过自回归和扩散基线。这是"下一个 token 预测"范式的真正挑战者之一，如果这类方法能扩展到大模型规模，推理成本（也就是所有人的 API 账单）有数量级下降空间。局限也要说清：实验只在 ~1 亿参数的小模型上做的，能否 scale 到千亿参数未经证实。

## 💬 今日吵架冠军：《我不信 AI 泡沫存在》（509 分 / 879 评论）

**文章论点**（作者 Matteo Raso）：AI 行业已承诺支出超 5 万亿美元，但其中大头是数据中心这种**一次性资本开支**，建完就降；Anthropic 的 S-1 招股书显示其每 1 美元算力换 2.08 美元收入，2026 上半年营收 163 亿（两年前才 3.86 亿）；Alphabet/Meta/英伟达市盈率稳定在 20 倍左右——互联网泡沫时是几百倍或干脆不盈利，"我从没见过主角公司估值这么'健康'的泡沫"；且"没有护城河"不等于不赚钱（麦当劳也没有护城河）；最后他诛心地补了一刀：泡沫论流行，本质是人们在"许愿"（wishcasting）世界能回到 ChatGPT 出现之前。

**反方（评论区主流，声音更响）认为这就是泡沫**，理由三条：

1. **折旧年限算错了**。最高赞评论（wmf）：数据中心不是仓库，成本的 80% 是 GPU，而 GPU 3-5 年就过时（新一代出来旧卡租金立刻腰斩），按 20 年摊销是致命误算——按 5-6 年算，需要的年收入直接翻 4 倍。有人补刀："2 万亿已投入的 GPU，未来 5 年每年要挣回 5000 亿。"
2. **"每 1 美元算力换 2.08 美元"是话术**。有人类比："如果忽略造车的成本，卖车也非常赚钱。"Anthropic 的 S-1 同时显示亏损在**扩大**而非收窄；而且这还没算获取用户的营销补贴和"免费额度"。
3. **竞争会把毛利打没**。有人指出文章完全没提 DeepSeek 等开源/低价模型："用户切换模型毫不费劲，这不是 Windows vs Linux 那种有生态护城河的战争；当对手只赚几分钱利润时，Anthropic 不可能维持一美元换两美元。"还有人给了个精准概括：泡沫的不是"AI"，是"OpenAI-Anthropic-xAI"这几家——中国的用法证明 LLM 投资本身可持续，但"花几万亿造一个只比中国模型好 1.2 倍、贵 100-1000 倍的模型"，祝好运。

**支持文章的一方**也不弱：技术必然成功≠估值正确，但反过来，互联网泡沫破了、互联网本身改变了一切——"泡沫的争议是时机问题，不是价值问题"（铁路、半导体、塑料都经历过同样的过度投资，最后投资者里还是有人赚翻）；还有人对文章结尾的心理学分析深表认同："人们想听 Ed Zitron（著名 AI 泡沫论者），是因为想有人告诉他们一切会回到'正常'。"

**我的倾向**：反方在**财务机制**上更扎实——GPU 折旧年限是硬伤，作者把 5 万亿按 20 年摊、算出"每年 2500 亿就能还上"，但 80% 的成本实际要在 4-5 年内回收，需要的年收入是万亿美元级别，目前全行业 AI 收入（乐观估计几百亿到一千多亿）差一个数量级。但作者在**叙事层面**说对了一件常被忽略的事：这轮和 2000 年最大的不同是主角公司现金流真实、市盈率不疯，所以即便"破"，形态更可能是投资减速+局部洗牌，而不是纳斯达克式的整体崩塌。一句话：**"AI 有没有用"和"现在这个价买不买得"是两个问题，混淆它们的人——无论多头还是空头——都在犯错。**
