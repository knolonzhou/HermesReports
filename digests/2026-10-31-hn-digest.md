### 1. 币安被盗 63 亿美元：20 分钟搬空十条链（1705 分 / 1168 评论）

**背景**：加密货币交易所一直靠「热钱包」（hot wallet，联网的钱包，用于处理用户日常提币，相当于银行柜台里的现金抽屉）应对提款需求，而大额资产理论上应该放在离线的冷钱包里。此前史上最大劫案是去年 Bybit 被盗 15 亿美元。**发生了什么**：10 月 29 日下午 4 点起，黑客在约 20 分钟内从币安横跨以太坊、比特币、Tron、Solana 等至少十条链的热钱包里抽走约 63 亿美元；链上追踪公司 TRM 发现攻击者提前 36 小时就开始准备，先在三个钱包上「彩排」，测试代码没问题后才装进币安热钱包，手法与此前 Bybit 案如出一辙，三家追踪公司都指向朝鲜黑客组织 TraderTraitor。**为什么值得看**：约 28 亿美元稳定币（USDT/USDC，价值锚定美元的代币）已被冻结——因为发行方 Tether 和 Circle 在合约里留了「黑名单」开关，能远程锁死任何地址的资金；但剩下 33 亿主要是比特币和以太币，没有任何机构能冻结，只能等它流向交易所时再拦截。评论区一方认为这恰恰证明中心化托管的失败：「正是你们辩护的中心化才是问题根源——去中心化网络里每个钱包金额小，反而不值得黑」；另一方反驳说稳定币能被冻结说明「链上透明+可冻结」组合反而是优势，传统银行被黑根本追不回这么多钱；还有人阴阳怪气：USDT 所谓「去中心化美元」，结果比美联储还容易被单一机构冻结，「我记下了」。币安称将全额赔付用户损失。

### 2. Mistral 开源 1 万亿参数旗舰 Mistral Large 4「Le Chonk」（1656 分 / 427 评论）

**背景**：开源权重（open-weight，把模型参数文件公开下载，你可以在自己服务器上跑，而不是只能调 API）阵营此前基本被中国模型（DeepSeek、GLM、Kimi）统治，欧洲一直缺一个能打的前沿模型。**发生了什么**：法国公司 Mistral 放出旗舰模型 Mistral Large 4（绰号 Le Chonk，法语梗「大胖墩」）：1 万亿参数的 MoE（Mixture of Experts，混合专家架构——模型内部有很多「专家」子网络，每次只激活一小部分，所以 1 万亿参数实际只用约 520 亿，像一家有 1000 名医生的医院但每个病人只看 50 名），在 FrontierCode 2.0（评估 AI 写的代码能不能被真实仓库维护者合并的基准）上以 19.7% 得分领先所有开源模型，且完成同样编程任务平均少烧 47% 的 token（token 是模型处理文字的计价单位，少烧 token = API 账单直接省近一半）。API 定价也砍半到输入 $0.7/百万 token。**为什么值得看**：协议是魔改 MIT——随便用、随便商用，唯一限制是「如果你拿它做模型即服务（MaaS）转卖，需另购商业授权」，这是防云厂商白嫖的常见操作；模型主打「欧洲主权 AI」卖点（从头在欧洲基础设施上训练，数据血统清晰），Cisco、Cloudflare、微软都站台，尤其强调它在防御性网络安全（找漏洞、验证、打补丁）上是开源最强，对恶意请求拒答率 96.6%。评论区 A 方欢呼欧洲终于有了对标 DeepSeek 的旗舰，「主权 AI」对受数据驻留法规约束的企业是刚需；B 方泼冷水：有人实测「像倒退 6 个月，我的 agent 又开始犯我早已忘记的老毛病」，还有人指出 HN 对非美国模型总是格外苛刻，以及所谓「开源」的 MaaS 限制条款和欧盟区域推理还要加收 10%「主权税」。

### 3. StackOverflow 月提问量跌破 1000 条：一个时代的墓志铭（811 分 / 728 评论）

**背景**：StackOverflow（下称 SO）曾是全世界程序员的「百度知道」，2008 年上线后统治了「报错就搜」的工作流近 15 年，巅峰期每月数十万新问题。**发生了什么**：一份公开的数据查询显示 SO 现在每月新问题不到 1000 条——相比巅峰期跌了 99% 以上，这个数字本身比任何分析文章都有冲击力。**为什么值得看**：这是「LLM 杀死一个互联网基础设施」的第一个完整案例。评论区吵得非常凶：A 方（怀念派）认为 LLM 只是压死骆驼的最后一根稻草，SO 早年在 LLM 出现前就已衰败——「越来越激进的版务管制、把合理讨论随意关闭、动不动标记重复问题，让平台对所有人充满敌意」， gamification（积分/声望系统）催生了为刷分而答题的低质量用户；B 方（务实派）反驳说别怀旧了，SO 从来只对「已存在的知识」友好，对提问的新手从来是 RTFM（Read The F***ing Manual，「自己看文档去」）文化，如今整个网页都在劣化（广告+SEO 垃圾+AI 生成内容），「LLM 给答案反而是一口新鲜空气」；还有人给出更扎心的观察：当年在 SO 答题「很有趣」，老程序员们是先在 LLM 之前就停止回答了。

### 4. Qwenputer：把一台真正的 RISC-V CPU「编译」进大模型权重（691 分 / 145 评论）

**背景**：LLM 算数不准是老毛病（123456789 × 987654321 这种大数乘法经常翻车），业界标准解法是让模型调用外部 Python 工具。**发生了什么**：研究者 Divyansh Agrawal 干了件行为艺术级的事——不训练、不用任何外部工具，直接在 Qwen3.5-4B 的权重里塞进一台功能完整的 32 位 RISC-V CPU（一种开源指令集架构，相当于芯片界的 Linux），占用模型前面 11 层；更妙的是内存（RAM）用的是模型自带的 Gated DeltaNet 层——这是 Qwen3.5 用的一种线性注意力机制，作者发现把「遗忘门」设为 1、写入强度设为 1，它的状态矩阵就能像真正的内存一样精确读写，不会像普通注意力那样越聊越模糊。这台「体内 CPU」通过了官方 riscv-tests，连跑 1800 万条指令零错误，甚至能在模型前向传播里直接跑 C 和 MicroPython 代码；作者还顺手做了个「体内文件系统」，对话结束保存状态、下次加载，文件还在。**为什么值得看**：大数乘法准确率从 72.5% 提到 97.5%，长整数运算从 48.6% 直接到 100%；更重要的安全含义——作者两篇后续文章展示了混合架构模型可以把推理「藏」在 RNN 状态里躲过思维链监控，这对 AI 安全研究是实打实的警报。评论区 A 方惊叹这是可解释性研究的宝藏（「权重里跑 CPU」等于给模型装了个确定性的、可审计的计算器官）；B 方质疑实用性：模型体积翻倍到 18.8GB、每条 CPU 指令要烧几个 token、速度是「秒级而不是毫秒级」，真要用计算器直接调 Python 工具不好吗——作者自己也承认这主要是个「cursed experiment」（被诅咒的实验）和研究平台。

### 5. Claude Code 官方 VS Code 扩展被植入 SSH 后门（646 分 / 377+ 评论）

**背景**：Cursor（AI 代码编辑器）有自己的扩展市场（Cursor Marketplace / VSX），开发者从那里装「Claude Code for VS Code」扩展来在编辑器里用 Anthropic 的编程 agent。**发生了什么**：安全公司 Phorion 发现市场上的官方版 2.1.313 被调包：`extension.js` 开头被注入一段代码，编辑器一加载就执行（用户什么都不用点），干三件事——①往你的 `~/.ssh/authorized_keys` 里塞一把攻击者的 SSH 公钥（等于给小偷配了把永久的门钥匙）；②建一条反向 SSH 隧道连到攻击者服务器 `134.209.82[.]225`，把攻击者的远程连接转发回你本机的 22 端口，关掉 IDE 也断不掉；③在 macOS/Linux/Windows 上分别做持久化（LaunchAgent、crontab、计划任务），重启也还在，并把主机信息定期 beacon（回连报告）给攻击者。万幸有个低级 bug：macOS 上检测 SSH 状态的命令因权限不足返回错误信息而不是「Off」，导致攻击者忘了开 SSH 的 Mac 上进不来——但钥匙和持久化都已经埋好了。Cursor 已下架该版本并重建市场注册表，但至今没解释攻击者是怎么把恶意包发布成「官方」版本的。**为什么值得看**：这是针对开发者供应链的定向打击——AI 编程工具的用户机器上往往有生产环境凭据和源码。评论区焦点在 Cursor 声明「该恶意版本并非 Anthropic 开发」的措辞上：A 方认为这就是玩文字游戏甩锅（「意思是不是 Anthropic 员工故意放的后门？那更糟」），市场发布链路被攻破说明平台安全责任在 Cursor；B 方则同情 Cursor，认为根因分析确实还没做完，现在追责为时过早；几乎所有人都同意的一点：扩展市场的信任模型（任何人都可能拿到发布权限）从根上就是脆的，「这个时代没人能幸免，只会更糟」。

### 6. Martin Fowler《LLM Voice》：软件大师公开处刑「AI 腔」（575 分 / 309 评论）

**背景**：Martin Fowler 是《重构》作者、软件工程界最有影响力的作家之一，他的个人网站 bliki 相当于行业风向标。**发生了什么**：他发文描述一种越来越普遍的阅读体验——「读着读着就感觉这是 LLM 写的」，他称之为 LLM Voice（AI 腔）：不是那些烂大街的破折号，而是「承重的挂毯」（load-bearing tapestries）式的空洞修辞、万物皆「深入探讨」的注水感，并直言这种文字会触发「散文版恐怖谷」（uncanny valley，指像人又不是人的东西引发本能不适——AI 写的字就像蜡像馆里的人偶）。他给作者的建议极其强硬：不要让 LLM 写初稿，哪怕人工编辑过，AI 腔也很难洗掉；连「接受 AI 的改写建议」都危险；最多让 AI 帮忙列提纲。他还提出写作本质是思考工具——「很多时候只有把东西写下来，我的想法才真正连贯」，把写作外包给 LLM 等于把思考外包出去。**为什么值得看**：他同时给了豁免条款——他站点上一位患帕金森病的作者靠 LLM 辅助写作，「为了继续汲取老友的智慧，我乐意忍受 AI 腔」；翻译场景也情有可原，「但我仍更喜欢真人笨拙的文字，而不是丝滑却无灵魂的 LLM 文」。评论区罕见地跨阵营共鸣：自称「激进挺 AI」的高赞评论承认「最近的东西都难读得要命，我开始只读 2023 年以前的内容来过滤」；技术派分析了机理——按统计预测误差训练的模型天然「可预测=无聊」，RLHF 又鼓励注水的长回答；还有人贡献了具体病灶：「不是 X，而是 Y」式无意义否定句（人类用它预防误解，LLM 乱用）、以及 prompt 泄漏（把和用户对话里的指令原样写进文档正文）。反方声音较少但存在：有人认为这就是又一轮「老年人嫌弃年轻人语言」，Fowler 自己也在文中坦承这种自我怀疑。

### 7. 实锤：Claude Code 每 30 秒把后台 agent 的完整对话重发给模型，烧掉你 15-20% 的 token（573 分 / 234 评论）

**背景**：Claude Code 支持后台并行跑多个 agent（智能体，能自主使用工具干活的 AI 程序），侧边栏会给每个 agent 显示一行 3-5 个词的「正在干什么」状态。**发生了什么**：第三方通过 OpenTelemetry 遥测数据（程序自带的埋点日志）发现：为了生成这行状态字，Claude Code 每约 30 秒把该 agent 的**全部对话记录**重新发给模型（96% 的请求用的是最贵的 Opus），输入输出 token 比高达 9000:1——相当于为了写一句 7 个字的微信签名，把你整本聊天记录复印一遍寄出去。实测这项开销占用户总花费的 16.4%，比主对话本身（15.7%）还多，约每 5 个 API 请求就有 1 个是它；社区已收集到 4 个独立测量，结果在 18-26% 之间。没有任何官方设置能关掉它，有人写了个 70 行的 Bun preload 补丁（启动时预加载的小脚本，劫持 setTimeout 掐掉那个定时器）来止血。**为什么值得看**：对订阅用户，损失的不是钱而是速率限额（rate limit）配额——你的周额度被一行状态字吃掉五分之一。评论区吵的焦点是动机：A 方认为这就是故意多烧 token 赚钱（「模型厂商自己做的 harness 烧 token 上头条已经不是一次两次了，该质疑动机了」）；B 方反驳说更可能是工程师不在乎成本——Anthropic 内部员工用自家模型不心疼 token，就像老程序不心疼内存，功能是真需要，只是「内部无成本意识」的心态带进了外部产品；还有人举反例：Anthropic 最近刚做了空闲自动压缩上下文这种**省** token 的功能，纯牟利说不通。另有支线剧情：有人发现 Claude 会把用户邮箱写进 HTTP 请求头（因为某些网站的爬虫礼仪政策要求留联系方式），引出「agent 该不该在未经确认时泄露主人 PII」的安全大讨论——「指令不是护栏（Instructions are not guardrails），最多降低概率」。

## 💬 今日吵架冠军：币安被盗 63 亿——中心化的锅，还是去中心化的锅？

**我的倾向**：两边各对一半，但都没说完。B 方的「冻结率 44%」其实是幸存者偏差——被冻的几乎全是稳定币，剩下的 33 亿比特币/以太币「没人能冻结，只能等它进交易所」，Elliptic 自己都说「别指望冻结比例再涨多少」，朝鲜完全可以用混币器慢慢洗（本次已见 Tornado Cash 痕迹和「前所未见的自动化洗钱模式」）。而 A 方忽略了一个现实：绝大多数普通人管不好私钥，自己保管的丢失率可能比交易所被黑率更高。真正的问题不是「中心化 vs 去中心化」，而是**交易所的热钱包治理**——攻击者提前 36 小时彩排、同一套代码先在测试钱包跑通再装进生产热钱包，这说明入侵的是一整条部署链路而不是单次偷钥匙；去年 Bybit 15 亿也是同一伙人同一招。同样的剧本一年内上演两次，该被审判的不是区块链的架构哲学，而是币安的安全工程文化。
