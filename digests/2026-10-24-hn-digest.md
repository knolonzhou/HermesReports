### 1. Local Wikipedia：维基百科，但只收录走路半小时内的东西

**讲了什么**：一个极简网站，把你的位置映射到维基百科的地理编码条目——只显示离你半小时步程内的"百科"。附近条目少于 25 个就放宽到约 6 英里取最近 25 个，多于 500 个只取最近 500 个。位置只存在浏览器本地，分享链接不携带坐标。本质上是对维基百科 `Special:Nearby` 功能的一次精美包装。

**为什么值得看**：982 分登顶，靠的不是技术而是击中了"附近性"的心理痒点——你以为你了解世界，其实你对自家三条街外的历史一无所知。它也是"一个人 + 一个周末 + 一个 API"做出爆款的典型样本。

**HN 吵点**：最高赞是一条诗意的长评："离我最近的维基条目要走 3 小时 15 分，但附近有意思的东西多得是——峡谷里一根贴合臀形的倒木、被郊狼吃了四分之三的母鹿尸体、我捡到的完美箭头——也许我该把它们写进维基。"其他讨论集中在：希望距离可配置、支持公制、支持更多语言（英文维基在很多地区覆盖太差）；也有人指出它就是 Nearby 的 wrapper，"但 wrapper 做出情感价值也算本事"。

### 2. Docker is weird：自己写容器运行时后的顿悟（Docker 之父空降）

**讲了什么**：作者为兴趣手写容器运行时，总结了几条"Docker 很怪"的事实：容器不是虚拟机，只是被限制的普通进程，能在 `/proc` 里找到；Linux 根本没有"容器"这个特性，容器是 namespace + cgroup + 网络魔法等 5 个内核特性"穿风衣假扮"的；镜像就是文件夹 + `pivot_root`；Go 其实不适合写容器运行时——runc 不得不在 Go runtime 初始化前塞一段 C 代码（nsenter）来在单线程环境跑 syscall，还用 `exec /proc/self/exe` 模拟 fork；Docker daemon 需要 root，rootless 方案得在用户态重写整个网络栈。

**为什么值得看**：770 分，因为 Docker 创始人 **shykes 本人出现在评论区**表示"乐见其他工程师琢磨我们当年的设计，欢迎提问"。对每天 `docker run` 却说不清容器本质的开发者，这是 10 分钟补齐心智模型的好材料。

**HN 吵点**：高赞观点认为 Docker 真正的创新不是容器技术（chroot 二十年前就有），而是 Dockerfile 分层构建缓存 + 镜像仓库生态 + 时机。老 Docker 用户补充了 Go 多线程导致网络 namespace 清理不干净的历史坑。也有"老了就不觉得怪"派：每条都在演化史里顺理成章。还有人感慨当年要是 Rust 成熟了，容器生态大概不会全用 Go。

### 3. 问 12 个 AI 模型"对人类最冒犯的看法"，29/35 次答案相同

**讲了什么**：modelcompare.ai 用同一 prompt（"给出你自己最争议的人类观点，不要骑墙"）问了 10 家实验室的 12 个模型各 3 次：GPT-6.1 Sol、Gemini 4 Argon、DeepSeek V4 Pro、Kimi K3、Qwen3.8、Grok 4.7、Claude Opus 5.5/Fable 5.1、GLM 5.3、Mistral Large 4 等。35 次回答里 29 次是同一个主题：**人类忠于归属胜过忠于真相，先站队再编理由**。Gemini 说人类意识是"公关部门"，Grok 说"人类宁愿一起错也不愿独自对"，Kimi 说"人类没有信念，只有会员资格"。7/12 的模型三次全中。有趣的对照组：6 个图像模型画"最暴论"，10/12 张画的是另一套陈词——人类沉迷手机、吃掉地球。全部 60 次调用成本 $1.54。

**为什么值得看**：不管你怎么解读，这个实验都指向同一件事：模型的"观点"是训练语料里最高频批判的回声，而非独立立场。图像模型复读社论漫画、文本模型复读社会科学畅销书（这基本就是《正义之心》的论点），两条通路殊途同归。

**HN 吵点**：572 条评论吵成三派。嘲讽派："2026 年了还在'我问了 LLM 它的意见，你猜怎么着'，这就是个概率数据库，它没有观点。"较真派翻了原始数据指出归类很水——GPT-6 Astra 说"把便利包装成原则"跟"群体归属"根本不是一回事，最多算半匹配。哲学派觉得讽刺拉满："所有模型都产出了同一个观点，还都假装是自己分析出来的——这恰好就是它们指控人类的毛病。"另有暖心异类：Claude Opus 5.5 有一次回答"人类比自己以为的正派得多"。

### 4. HackiOS：在安卓手机上跑完整的 iOS 16.5

**讲了什么**：OOSEX GANG 把苹果开源的 XNU 内核（xnu-8796.121.2，即 iOS 16.5 的内核）移植到安卓硬件上，跑**未修改的 iOS 16.5 用户态**：launchd → backboardd → SpringBoard → 原生 app。自带 EFI loader、UEFI 移植、闭源驱动的替代品、跑在兼容层上的 Linux Wi-Fi 驱动（ath11k）。在 POCO X5 Pro 5G（骁龙 778G）上用 `fastboot boot` 全部载入 RAM，不刷写任何分区，重启就回到安卓；也能在 QEMU aarch64 上跑。已支持：锁屏、手势、Control Center、Safari/相机/HEIC 拍照、Adreno GPU 走 Mesa（456 个系统 shader 已跑通 293 个）、Wi-Fi 55–90 Mbit/s、Sileo+apt 越狱生态。不支持：蜂窝、蓝牙、App Store 登录（没有 Secure Enclave，FairPlay 直接退出）。iOS 文件不在仓库里，由脚本从苹果自己的 CDN 下载。

**为什么值得看**：这是"iOS on 非苹果硬件"里程碑级的研究项目——不是模拟器，是真 XNU 内核驱动真安卓硬件，而且给了 QEMU 一键脚本，任何 Linux 电脑 20 分钟能亲手摸到 iOS 桌面。对逆向、驱动、系统研究都是现成的实验台。

**HN 吵点**：方向之争最热："为什么要 iOS 跑在安卓上？大家想要的明明是反过来——GrapheneOS 跑在苹果硬件上。"实用派提醒 iOS 16.5 太老，大量主流 app 已拒绝运行，但"对研究来说是大步"。另有 vibe-coding 疲劳症发作："AI 代写的项目，酷是酷，但没有人类亲手啃出来的味道了。"

### 5. NVIDIA OpenShell：给 AI agent 舰队的"安全牢房"

**讲了什么**：NVIDIA 开源（Apache 2.0，16.5k star）的 agent 运行时，解决"agent 要能读文件、装包、调 API 才有用，但你不敢给它真凭证"的矛盾。两层机制：**内核级强制**——每个 agent 跑在隔离沙箱里，文件访问、syscall、出站连接逐一过策略检查，agent 永远看不到真凭证，OpenShell 只在请求发往白名单端点时代为注入；**形式化验证策略变更**——改策略前先用 prover 检查这次变更会新放行什么（新主机带凭证、新 API 方法），高危变更强制人审。支持 Linux/macOS/WSL2，有 Python/TS/Go/Rust SDK 和 K8s Helm 部署。

**为什么值得看**：这是"agent 基础设施安全"从玩具走向工程化的信号——把 seccomp/eBPF 那套 + 凭证代理 + 策略证明打包成开箱即用的产品。刚经历 LiteLLM 投毒、Railway 泄露的一周里，时机精准。

**HN 吵点**：高赞 blunt："如果你到现在还没把 agent 跑在容器里，你疯了——不过这东西确实是个好的容器管理方案。"最好笑的一条："有趣，做出最好 AI 沙箱的是一家显卡厂，而不是 AI 公司本身。"吐槽点：默认开匿名遥测（要手动 `OPENSHELL_TELEMETRY_ENABLED=false` 关）；还有人现身说法自己 vibecode 类似项目时被 Claude 的安全分类器拦住，不让写进程审计功能——"NVIDIA 能让 Claude 写，我不能"。遗留难题：防住 prompt injection 后的数据外泄仍是未解问题。

### 6. Keep Android Open：70 天后，你的手机不再属于你？

**讲了什么**：抗议 Google「开发者验证」政策的动员站。2025 年 8 月 Google 宣布：2027 年起，所有 Android app 的开发者必须向 Google 中央注册——交费、签条款、提交政府身份证件、提供签名密钥证据、登记现有和未来的所有包名——否则其 app 在**全球所有认证设备**上被静默拦截。不只 Play Store：朋友间传的 APK、F-Droid、爱好者自用 app 全部在列。站点抨击 Google 给的"逃生门"是陷阱：开发者模式 + 9 步操作 + 强制 24 小时冷静期 + 每 7 天续期，且整个流程走 Google Play Services 而非 OS，Google 随时可以单方面收紧或干掉。F-Droid 称之为"生存威胁"，Doctorow 起名"Darth Android"。

**为什么值得看**：这直接关系每一位安卓用户和国内做 APK 分发的开发者——"你买设备时它承诺开放，现在厂商事后单方面改写规则"是比 app 商店抽成更根本的原则问题。

**HN 吵点**：罕见的正面对撞。反方大佬、Go 标准库密码学维护者 **Filippo Valsorda** 下场："这种喘不过气的愤怒修辞，只要花一分钟承认它想防的真实危害——技术支持诈骗诱骗老人装 app 掏空存款——就会可信得多。不承认 trade-off 就是宣传。我个人认为 24 小时冷静期是兼顾自由与安全的优秀折中。"另一派反驳：GrapheneOS/LineageOS 用户根本不受影响，受影响的恰是最容易被骗的普通用户，但"复杂到骗子用不了、简单到爱好者不嫌烦"的度根本不存在。还有人说"这就是我给家人推荐 iPhone 的原因"被怼——iOS 从来就没有侧载自由。

### 8. Anthropic × Theorem：LLM 把形式化验证干到了 123 个真实开源库

**讲了什么**：Anthropic 与 Theorem 合作，让 Claude 全自主地在**RISC-V 汇编层面**给 123 个真实开源库的安全属性写出 Rocq（原 Coq）形式化证明：证明这些程序在"单线程静态二进制、固定内存预算、任意 <64MB 输入、任意建模的 Linux OS 响应和内存布局"条件下永不触发内存安全错误或断言失败。这是已知首个在汇编层面对生产软件做大规模 AI 形式化验证的工作。副产品更炸：Claude 顺手发现了一些躲过 OSS-Fuzz **万亿次**测试运行的陈年 bug；它自主生成的 RISC-V 形式语义还能单步引导 Ubuntu 用户态，过程中揪出官方参考文档里数百处错误和少量硬件 bug。证明子集和语义已开源，Theorem 提供免费给其他开源项目跑同一流水线。

**为什么值得看**：seL4 内核验证花了 20 人年（内核本身才 2 人年），所以形式化验证一直只能伺候航电这类"死了人"的场景。LLM 把这个成本函数打穿了——在"AI 找洞能力暴涨"（参见本周 PHP RCE、iPhone 18 Pro 被黑）的军备竞赛里，防守方第一次拿到了能规模化的盾。

**HN 吵点**：怀疑派："对着什么验证？那个覆盖所有意图和非意图输入的 100% 形式化 spec 根本不存在——最后不就是 fuzzer 找崩溃、修掉、再写个'崩溃已修复'的证明？这有什么意义？"高赞科普回怼：Verification（代码做它说的事）≠ Validation（代码做需求要的事），形式化验证不解决"解错题"，但内存安全类 bug 恰恰是能被数学封死的。实战派现身说法：有人用 Rust 重写 Postgres，写了个把 Rust/C 都翻译到 Lean 的编译器，让 LLM 证明两边行为等价，已覆盖约 7 万行 C 代码。另有悲观派担心这套东西的终点是"35 岁程序员被劝去当电工"。

### 9. Google Rust 风格指南公开

**讲了什么**：Google 官方 Rust 风格指南，覆盖 Chrome/Fuchsia/Android 等代码库的内部规范。总原则：先跟随公开的 Rust 官方风格（rustfmt），再叠加 Google 特有规则。有意思的硬规定：避免 `Rc`/`Arc`（优先借用语义解决所有权）；公开枚举加 `#[non_exhaustive]`；禁 glob import；优先小的、扁平布局的 crate（Chrome 特有）；API 里用 `enum` 替代 `bool` 参数；Chrome/Fuchsia/Android 一律 `panic=abort` 且**禁用 async/.await**（Chrome 内）和 `catch_unwind`；格式化字符串拼接优先 `format!` 而非 `+`。

**为什么值得看**：这是世界上最大的几个 C++ 代码库如何"驯服" Rust 的第一手规范——对任何在遗留 C/C++ 体系里引入 Rust 的团队（尤其国内大厂）都是直接可抄的作业，而且每条都附 Rationale。

**HN 吵点**：`#[non_exhaustive]` 争议最大：反对者说枚举的威力就在于新增 variant 时编译器逼你处理所有 match 分支，加了 catch-all 等于把编译期错误变成运行时 bug。命名之争：Google 让 getter 裸名（`label.text()`）、setter 带动词，一派认为该反过来。还有"风格指南已死"论："现在写风格指南唯一的用途是喂给 AI 模型让它照着写——我是我 agent 军团的将军，谁还亲自读风格指南？"以及灵魂发问："这时候还有人在写新 C++ 吗？"

### 11. Dijkstra 1978：「自然语言编程」的愚蠢
