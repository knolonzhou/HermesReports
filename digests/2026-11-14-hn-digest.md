### 2. Rust 1.100：整数版本号破百，"never 类型"熬了十年终于转正（841 分 / 301 评论）

**背景**：Rust 每 6 周发一个新版本，版本号从 1.0 一路爬到现在——1.100 是第一个三位数版本号，社区戏称"百年老店"（其实才 11 年）。**发生了什么**：这个版本转正了几个等了很久的功能：① **never 类型 `!`**（表示"这个函数永远不会正常返回"，比如死循环或直接崩溃的函数，编译器从此能更聪明地检查这类代码，这个特性从 Rust 1.0 时代就在讨论，拖了近十年）；② **自定义内存分配器**（程序可以自己决定从哪块内存池拿内存，游戏、嵌入式场景等了很多年）；③ **依赖冷却期**（dependency cooldown，可以设置"只允许安装发布超过 N 天的依赖包"——因为供应链攻击的常见套路是黑客劫持热门包后立刻发恶意新版，冷却期相当于"新菜先放 48 小时没人中毒再上桌"）；④ `cargo install` 默认锁定依赖版本。**评论区两派**：A 方（稳定 ABI 派）借里程碑版本再次呼吁做稳定 ABI（应用程序二进制接口，即编译好的库之间约定好"插头形状"，不同编译器版本编出来的东西也能互相调用，C 语言就是这么活到今天的），认为没有它 Rust 库就必须人人从源码编译；B 方（包括 Rust 团队成员 JoshTriplett 亲自下场解释）反驳说 Rust 的泛型机制让稳定 ABI 极其困难，强行做会像 C++ 那样被历史包袱锁死语言进化，而且社区已有更轻量的 crABI 提案在推进——"稳定 ABI 听起来美好，但代价可能是永远不能改内存布局"。
