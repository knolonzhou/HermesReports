### 1. Java4Shell：OpenJDK 的 Base64 解码器里藏着一颗 9.2 分的雷（1129 分 / 310 评论）

**背景**：Java 卖了 30 年"内存安全"人设——语言运行时自动管理内存，理论上不会像 C 那样出现"越界写内存"（程序往不该写的内存地址塞数据，是互联网上最常见的一类漏洞）。但 Java 运行时的底层（JVM，即 Java 虚拟机）本身是 C/C++ 和手写汇编写的，为了性能，解码 Base64（一种把二进制数据转成纯文本的常用编码，登录凭证、文件上传、网络报文里到处都是）时会调用 CPU 的 AVX-512 专用指令一次处理 64 个字节。**发生了什么**：安全公司 Calif 发现，给解码器喂 64 个 `A` 加一个 `=` 号这种畸形输入，底层汇编会把输出长度算成负数，导致多写 62 个字节到相邻内存——在 Keycloak、Jira、Confluence、Jenkins、Artifactory 等主流 Java 应用上，**不用登录**就能远程执行代码（RCE，Remote Code Execution，攻击者在你服务器上跑自己的程序）。CVSS 4.0 评分 9.2/10（满分 10，属于"最高危"档）。受影响的是 OpenJDK 17.0.6 之后所有版本及其衍生发行版（Corretto、Temurin、Zulu……），但**只限带 AVX-512 VBMI 指令集的 x86-64 CPU**（Intel Ice Lake 及以后、AMD Zen 4 及以后），ARM 服务器不受影响。**为什么值得看**：一是影响面——90% 的财富 500 强跑 Java，银行、电信、航空全在里面；二是发现方式——研究员说他让 OpenAI 的 Codex 去审计 JVM 源码，1 小时找到漏洞、2 小时写出第一个 exploit，token 花费不到 200 美元，他们自称"半人马黑客"（centaur hacker，人出方向、AI 出算力）；三是团队顺势提出"vibe-uncoding"概念：用 AI 把系统里根本没人用的功能整段删掉来缩小攻击面——这个洞恰好藏在"为极少数高吞吐场景做的优化，却让所有人陪着担风险"的代码里。**评论区争论**：A 方（恐慌派）认为"AI 会大幅加速漏洞武器化，别信'短期内不会大规模利用'的官方安慰"——有人举例：拿着这个半成品的堆内存泄露 exploit，可以横扫全球几百家银行的 Keycloak；还有人回忆 PHP2Shell 发布时 AI 两小时就攻下了一个真实网站偷走比特币。B 方（冷静派，如 izacus）反驳：这个洞的利用条件清单长得吓人（特定 CPU、特定 GC、堆布局要"按摩"到位、对网络延迟敏感），"对每个安全公司的自我营销帖都无脑恐慌不是理性行为"。另有实用干货：打不了补丁的可以先加 JVM 启动参数 `-XX:-UseBASE64Intrinsics` 关掉硬件加速 Base64 临时缓解；Semgrep 发布了免费检测脚本；甚至有人发现 nginx 完整缓冲请求体能挡掉部分攻击。

### 2. Cloudflare 罕见下场：Quad9 撤出法国只是"矿井里的金丝雀"（852 分 / 405 评论）

**背景**：Quad9（9.9.9.9）是瑞士公益基金会运营的公共 DNS 解析器（DNS 是互联网的"电话簿"，把域名翻译成 IP 地址；公共解析器就是任何人都能免费用的公共电话簿）。上个月法国法院裁定它必须屏蔽盗版域名否则按日罚款，Quad9 选择直接退出法国（本报 10-23 已详报）。**发生了什么**：这次是 Cloudflare 官方博客发文声援，标题用了"煤矿里的金丝雀"（矿工带金丝雀下矿，鸟先中毒报警——意指 Quad9 是先倒下的预警信号）。文章透露了更大的雷：比利时法院已下令 Cloudflare、Google、Cisco 在 2027 年 1 月前开始做 DNS 屏蔽，否则罚款——三家已上诉。Cloudflare 的核心论点是：DNS 屏蔽一秒钟就能绕过（换个解析器或直接输 IP），没有任何证据表明它减少了盗版，却会让整个域名下的合法内容陪葬，而且公共解析器是全球性的，一个国家实际上在替全世界做内容审查。**为什么值得看**：这是 1.1.1.1 的运营者第一次直白说"下一个可能就是我"，公共 DNS 这个互联网基础件正在被版权执法一层层逼退。**评论区争论**：A 方（主流）认为这是"自由全球互联网解体的开端"，欧洲正在用过度监管把互联网切成一个个"国家局域网"（balkanization，巴尔干化——像巴尔干半岛那样碎成一地）。B 方专门怼 Cloudflare 的发言资格："一个靠浏览器指纹识别把非'企业认可'流量挡在门外、把半个互联网塞进自家验证码后面的公司，也配谈'自由开放的互联网'？"——认为法国的做法确实恶心，但互联网早就既不自由也不开放了，Cloudflare 只是选择性发声。这个反驳戳中了 Cloudflare 一边当"互联网守护者"一边当最大中间人的双重身份。

### 11. 能量推理机（EBR）：1.8M 参数小模型，推理算力省 345 倍（256 分 / 39 评论）
