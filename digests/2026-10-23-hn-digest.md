### 1. PHP2Shell：AI 挖出 PHP 核心 RCE，全网紧急打补丁 ⭐今日必做：升级 PHP

**讲了什么**：Wiz Research 联合 OpenAI、Calif 在 PHP 核心引擎发现两个内存安全漏洞（CVE-2026-109618/109619，CVSS 9.2），可无需认证远程执行代码或读取进程内存里的密码、API key。漏洞根源是 PHP 处理 fatal error（尤其 OOM）时留下损坏的内部状态被后续请求复用，从 PHP 5.4 起潜伏十余年，影响全球约 70% 网站（WordPress/Drupal/Joomla 均被演示攻破）。10 月 21 日 PHP 发布 8.2.35 等修复版本。

**为什么值得看**：这是"AI 改变漏洞经济学"的标志性事件——漏洞链复杂到人类研究员难以规模化利用，但 Gemini 4 Argon、GPT-5.6 等前沿模型把 exploit 开发和跨环境适配压缩到几小时。Wiz 直接把它对标 Heartbleed 和 Log4Shell。另外披露过程本身也是大瓜：CVE 号和错误的"CVSS 10.0"提前泄露，Calif 抢发营销视频（带动漫妹），Chainguard 提前 6 小时破禁运发镜像，PHP 基金会在博客里逐一点名。

**HN 吵点**：一派认为"补丁都发了 2 小时 Docker 镜像还没有，协调披露流程烂透了"；另一派在追问临时缓解措施（`session.upload_progress.enabled = Off` 是否够用）；还有大量人吐槽泄露者 petecooper 本人在 HN 发帖认领"是我泄的，对不起"。跑 PHP 生产的读者：立刻升级，别赌。

### 2. "Eight Bits of Trust"：eMudhra CA 私钥就是数字 4

**讲了什么**：印度 CA 机构 eMudhra 的 8 张中间证书（6 张 TLS + 2 张代码签名，2025 年 4 月生成）私钥全是单个字节——d=4、56、115、156……Scott Helme 在自己笔记本上不到一秒全部暴力还原（P-384 曲线私钥本应是 384 bit 随机数，实际熵只有 8 bit）。这些中间证书还被 Sectigo 交叉签名，10 月 17 日被研究者报告后 Chrome/Firefox/Safari 火速封杀，eMudhra 随即宣布彻底退出全球 SSL/TLS 业务（占其营收约 1%）。

**为什么值得看**：浏览器用户没事（CT 强制 + 已封禁），但真正的雷在**非浏览器 TLS 客户端**：curl、Python、Node、Go、Java、CI/CD、IoT 设备默认不查吊销也不查 CT，Scott 实测 curl 对着伪造的 `api.stripe.com` 证书直接 `verify ok`。无法升级的设备会信任这些证书直到 2039 年过期。行动项：更新系统 ca-certificates、certifi、Node、基础镜像并重建容器。

**HN 吵点**：共识是"这大概率是密钥仪式脚本 bug + 人工拿错密钥，不是内鬼"；争议在于 CA/B 生态为什么能给背景存疑的机构发牌照，以及 mitmproxy 干脆加了个 `--emudhra` 玩梗选项（573 分）——HN 表示"笑不出来，因为真有代码签名中间证书在外流"。

### 3. LiteLLM 1.107.0 被投毒：窃取 SSH/云凭证/AI token + 常驻后门

**讲了什么**：PyPI 上的 LiteLLM 1.107.0（10 月 21 日 11:39-13:23 UTC 在架）被植入 `cook.py` 凭证窃贼和 `sitecustomize.py` 后门。窃贼横扫 SSH 密钥、AWS/Azure/GCP 凭证、浏览器密码、shell 历史，甚至 Claude Code/Cursor/Copilot 等 **16 类 AI 开发工具的 token**，加密后发往 `www.litellm[.]dev`；后门每小时从攻击者 GitHub 仓库读取新 C2 地址并 `exec()` 远程代码。攻击者用窃取的三名开发者 GitHub CLI 凭证绕过分支保护，把发布流水线指向仿冒仓库 `Berri-AI/litellm`。Docker 镜像 `v1.107.0`/`latest` 同期也带毒。

**为什么值得看**：这是 LiteLLM 短期内第二次供应链事故（HN 高赞："一次可原谅，两次是渎职"）。用了 `litellm==1.107.0` 的机器应视为已沦陷：轮换所有凭证、检查 `/tmp/.pc_once_*` 和 `PRIVCOLLECT_ACTIVE=1` 等 IoC。注意 `.pth` 文件机制意味着**主机上任何 Python 进程启动都会触发窃贼**，哪怕从没 import litellm。1.106.2 和 rc 版本是干净的。

**HN 吵点**：一周内 Google Cloud 宕机、eMudhra、TiDB 泄露 10.6TB、PHP2Shell、LiteLLM 连环出事，评论区开始认真讨论"AI 基础设施是不是攻击者的新单点"；不少人对被 Google ADK 等框架间接拖进 litellm 依赖表示愤怒。

### 11. o(n log n) 整数乘法新论文 + Lean 形式化进展
